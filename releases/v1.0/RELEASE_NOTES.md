## Summary

This is the first public frozen release of *Observability Boundaries for Near-Critical Weil Blocks: A Finite-Dimensional Analysis of Off-Line Zero Collisions*.

The release contains synchronized Japanese and English manuscripts and a full frozen source/audit package. The mathematical core is restricted to a fixed finite-dimensional, fixed-collision-ordinate, single-pair local analysis.

## Main frozen results

- explicit quadratic collision coefficient for the pair block;
- continuous-observable collision/no-depth-uniform-gap statement, explicitly treated as an elementary continuity consequence;
- exact negative direction in the nondegenerate local branch;
- distinction between exact negative detection and vanishing geometric robustness margin;
- higher-order real-symmetric transverse-jet classification
  `lambda_-(delta) ~ -2 m ||w||^2 delta^(4q+2)`;
- explicit separation of proved single-pair results from open aggregate and infinite-dimensional questions;
- self-contained code-to-paper bridge from the pinned Alpöge–Furman / Anthropic formalization snapshot.

## Scope guardrails

This release does **not**:

- prove the Riemann Hypothesis;
- claim that every higher-order branch is realized in the actual taper family;
- derive a general interacting multi-pair aggregate spectrum theorem;
- establish an infinite-dimensional no-go theorem;
- claim historical priority for the `4q+2` classification.
